# `POST /v1/mems/query` — 记忆召回

跨活跃 L1 情景记录与 L2 蒸馏知识召回记忆。调用方自行负责从结果中组装上下文。

## 当前检索信号

- L1 情景召回
- Qdrant 语义召回
- L2 摘要召回
- 基于意图的排序逻辑
- L2 画像、事实、事件的结构化查询召回

## 当前实现说明

当前向量召回重点是活跃 L1 和 L2 摘要。画像、事实、事件仍主要走结构化查询和排序逻辑。

## 响应字段

- `source`：记忆来源（`l1_episodic`、`l2_profile`、`l2_fact`、`l2_event`、`l2_summary`）
- `content`：记忆文本
- `score`：相关度分数
- `source_l1_ids`：可追溯的 L1 记录 id，用于证据溯源
- `session_id`：可选来源会话（仅 L1）
